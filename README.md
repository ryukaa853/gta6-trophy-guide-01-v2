Leonida Platinum is an offline guide and tracker for all 55 GTA 6 PlayStation 5 trophies: a checklist saved in the browser, a five-stage roadmap to the platinum, the 13 missable trophies flagged, a next-up planner, and a cited guide for every trophy — all as static files that work with the network off.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser.
